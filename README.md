# DataVault — Learning Resources

Public resource files for **DataWithPranav** (Excel, SQL, Power BI, and more).

Instagram followers receive folder/file links from this repo via DataVault automation  
(comment a keyword on a Reel → private reply with the correct URL).

> App code lives in a separate private repo: `DataVault_pvt`  
> This repo is **only** datasets and project files.

---

## Folders

| Folder | Series / content |
|--------|------------------|
| `excel-series/` | Excel practice datasets |
| `sql-series/` | SQL practice files |
| `powerbi-series/` | Power BI project files |
| `job-simulation/` | Job simulation resources |
| `misc/` | One-off resources |

Add new series as a new folder. Keep one clear README inside each series.

---

## How DataVault uses these links

1. Upload files here (e.g. `excel-series/sales-dataset.xlsx`)
2. Copy the GitHub URL (folder or file)
3. In DataVault admin → create a **Resource** with that URL
4. Bind your Reel(s) + keyword (`DATASET`) to that resource

Series tip: 4–5 reels can share the **same** folder URL.
